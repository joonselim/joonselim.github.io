BFS (breadth-first search) explores a graph level by level. It starts from one node, visits all its neighbors first, then their neighbors, and so on.

The key is a queue. Take a node out of the front, and add its unvisited neighbors to the back. Because of this order, every node at distance 1 is visited before any node at distance 2.

Here the graph is a grid. Each cell is a node, and it connects to the open cells above, below, left and right. The number in each cell is its distance from **S**.

## Why it finds the shortest path

BFS reaches every node at distance `d` before any node at distance `d + 1`. So the first time it reaches a node, it took the fewest steps possible.

This only works when every edge costs the same. If edges have different weights, you need Dijkstra instead.

## Code

```python
from collections import deque

def shortest_path(grid, start, goal):
    rows, cols = len(grid), len(grid[0])
    queue = deque([start])
    dist = {start: 0}

    while queue:
        r, c = queue.popleft()
        if (r, c) == goal:
            return dist[(r, c)]
        for dr, dc in ((0, 1), (1, 0), (0, -1), (-1, 0)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 0 and (nr, nc) not in dist:
                dist[(nr, nc)] = dist[(r, c)] + 1
                queue.append((nr, nc))
    return -1
```
